## Platform overview

MAVULA separates financial concerns across three distinct API services:

<CardGroup cols={3}>
  <Card title="Identity Access" icon="user-shield" href="/api-reference/identity-access/overview">
    OAuth 2.0 and OpenID Connect. Issues JWTs carrying tenant, role, and permission claims. Base URL: `identity.mavula.dev`
  </Card>

  <Card title="Ledger Core" icon="building-columns" href="/api-reference/ledger-core/overview">
    Financial source of truth. Accounts, balances, adjustments, products, and projections. Base URL: `ledger.mavula.dev`
  </Card>

  <Card title="Workbench" icon="gears" href="/api-reference/workbench/overview">
    Async job orchestration, legacy interoperability, and platform status. Base URL: `workbench.mavula.dev`
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Get a token">
    Use the authorization code \+ PKCE flow (for human operators) or client credentials (for backend services) to obtain a bearer token from Identity Access.
  </Step>
  <Step title="Verify your identity">
    Call `GET /api/v1/me` to confirm your token's tenant, roles, and permissions before making financial calls.
  </Step>
  <Step title="Make your first financial call">
    Create an account in Ledger Core using your bearer token and a unique `Idempotency-Key`.
  </Step>
  <Step title="Explore the guides">
    Follow the hands-on guides for account lifecycle management, financial adjustments, payment jobs, and configuration.
  </Step>
</Steps>

<Note>
  All mutating requests to Ledger Core and Workbench require an `Idempotency-Key` header. Always send a `X-Correlation-ID` header on every integration call to trace requests across service boundaries.
</Note>
