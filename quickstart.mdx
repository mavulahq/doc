This guide uses the OAuth 2.0 authorization code flow with PKCE, which is the correct grant type for human operators authenticating through a browser or native interface. Before you run the first step, complete the authorization redirect described in the [Authentication](/authentication) guide to obtain your `AUTHORIZATION_CODE` and `ORIGINAL_CODE_VERIFIER`. Once you have those in hand, the four steps below take you from a raw code to a funded account balance in minutes.

<Note>
  **Token handling.** Keep access tokens in memory only - never write them to disk, logs, environment files committed to source control, or support requests. Rotate refresh tokens atomically: persist the replacement before discarding the previous value. Authorization codes are single-use; discard them immediately after the exchange in Step 1.
</Note>
